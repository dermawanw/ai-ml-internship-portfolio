# Checklist Proyek

Sebuah proyek baru boleh dipasang sebagai “unggulan” jika semua bagian berikut selesai.

- [ ] README menjelaskan masalah, tujuan, cara kerja, data, metrik, dan hasil.
- [ ] Instruksi instalasi dan menjalankan proyek berhasil dari lingkungan bersih.
- [ ] Ada baseline sederhana sebelum model yang lebih rumit.
- [ ] Split data dan pencegahan leakage dijelaskan.
- [ ] Eksperimen dapat diulang dengan seed dan versi dependency.
- [ ] Ada tes otomatis untuk bagian penting.
- [ ] Ada analisis minimal tiga contoh kegagalan.
- [ ] Tidak ada data besar, secret, token, atau password di repo.
- [ ] Ada gambar/demo dan satu kalimat hasil yang terukur.
- [ ] Lisensi data dan kode dicatat.
